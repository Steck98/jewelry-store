# Jewelry Store

A full-stack e-commerce web application built with **Python and Django**, currently under active development.

The project is designed as a portfolio application with a strong focus on **backend development, database design, business logic, authentication, order management and software quality**.

The frontend is kept clean and minimal, while the main goal of the project is to demonstrate how a real-world e-commerce application can be structured and developed using Django.

> **Project status:** 🚧 In active development

---

## Overview

Jewelry Store is an e-commerce application for browsing and purchasing jewelry products.

The application is being developed around a realistic shopping workflow:

**Browse products → View product details → Add to cart → Checkout → Place order → View order history**

The project is intentionally focused on the core functionality of an online store rather than implementing unnecessary features. The goal is to build a solid and maintainable backend with clear separation between products, users, carts and orders.

## Backend Focus

Although the project includes a complete frontend interface, the main purpose of the project is to demonstrate backend development with Django.

The project focuses on:

* Designing relational database models
* Django ORM
* Model relationships
* Authentication and authorization
* Business logic
* Data validation
* Stock management
* Cart and order logic
* Handling user-specific data
* Maintaining historical order information
* Building reusable Django applications
* Testing backend functionality

The project is being developed incrementally, with functionality added and tested as the application grows.
